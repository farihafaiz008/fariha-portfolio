# Personal Portfolio Website

## Overview
This is my personal portfolio website developed using HTML, CSS and JavaScript. The website showcases my education, skills, projects, achievements, publications, hobbies and contact information.

## Features
- Responsive portfolio website
- Home page with introduction
- About section
- Education timeline
- Technical and soft skills
- Projects showcase
- Achievements section
- Publications section
- Hobbies section
- Contact page
- Download CV button
- GitHub and LinkedIn profile links

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Font Awesome

## How to Run Locally

1. Clone the repository

```
git clone https://github.com/farihafaiz008/fariha-portfolio.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

OR

Run the project using VS Code Live Server.
